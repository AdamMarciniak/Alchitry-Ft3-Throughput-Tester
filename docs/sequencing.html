usb3-tester · pulser branch · 100 MHz sequencer clock

One element, start to finish

The transmit sequencer owns the timebase. It walks the aperture element by element — shift the mux chain, latch it, settle, fire a bipolar burst — and the receive side is slaved to it: the single-cycle tx_sync pulse at the first HV edge is what arms the acquisition window and stamps the element id into the frame header. Stop the pulser and the ADC stream goes quiet, by design. Everything below is drawn from the RTL in tx_sequencer.v, ctrl_decode.v, afe_rx.v and afe_stream.v; the sliders apply the same clamps the hardware does.

02 / THE ELEMENT PERIOD

What happens between two bursts

Time zero is the first HV edge — the same instant tx_sync fires. The chart is one full element period, drawn to scale from the values below. The important shape: the pulser's receive window is long, and nothing at all happens inside it. The chain shift for the next element used to be buried in it, early, where the echo is ringdown-dominated anyway; it now waits until the window has closed, so the entire receive period is free of chain clocking. That costs 6.4 µs of element period per element, and it is the trade the design makes on purpose.

05 / WHAT COMES BACK

One receive window is one frame on the bus

Every window is a header word followed by packed data words on the fast pipe. The host finds frame boundaries by testing (word >> 22) == 0x384.

Word 0 · frame header
31:240xE1
23:2200 guard
21:16elem[5:0]
15:0frame_cnt

elem is the aperture position latched from tx_elem at tx_sync — 0 is the left-most element, 47 the right-most. mux_code() in the sequencer is the only place the connector's scrambled wiring is described, so the host can index its geometry table with this field directly.

Words 1..N · two samples per word
31:28seq n+1
27:16sample n+1
15:12seq n
11:0sample n

Older sample in the low half, so a little-endian uint16 view on the host is already in time order. The 4-bit sequence tag counts per sample and pairs are dropped whole if the FIFO backs up — a drop shows up as a discontinuity, never as a torn word.
